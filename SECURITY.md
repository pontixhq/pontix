# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
**Security** tab of this repository, then **Report a vulnerability**.

Please include the affected version, steps to reproduce, and the impact you
expect.

## What to expect

- We reply to every report within **3 business days**.
- Critical issues are fixed and released within **30 days** of confirmation.
- We credit reporters in the release notes unless they ask us not to.

## Scope

Pontix reads Odoo source code and produces reports. Findings that leak
secrets from analysed code, execute code from analysed modules, or tamper with
reports or license verification are in scope.
